# 🏨 Astra Hotels & Suites

A full-stack multi-property hospitality website with immersive UI, built for a hotel chain across 8 Bangalore locations.

## 🔗 Live Demo
[astra-site.vercel.app](https://astra-site.vercel.app)

## ✨ Features
- GPS-based nearest hotel finder
- 360° room viewer (Three.js)
- Per-room booking modal with live GST calculator
- Mega nav with Quick Book panel
- Smooth scroll with Lenis + GSAP ScrollTrigger animations
- Mobile responsive

## 🛠 Tech Stack
- **Frontend** — Next.js 14, TypeScript, Tailwind CSS
- **Animations** — GSAP, Framer Motion, Lenis
- **3D** — Three.js
- **Deployment** — Vercel

## 📍 Properties
8 locations across Bangalore — Electronic City, HSR, Koramangala, Marathahalli, Whitefield and more.
